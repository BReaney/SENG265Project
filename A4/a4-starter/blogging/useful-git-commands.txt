################# Git Command Line Commands That I Use ###############################

===================================
Staging and committing changes
===============================
#add file(s) to staging, multiple files can be added at once:
	git add <path/filename.type>	

#shows current branch, if the branch is up to date with the remote, changes staged for commit, changes not staged for commit:
#NOTE: the file will need to be restaged if you add more changes
	git status			

#commit changes to local repo, -m toggles adding a message:
	git commit -m '<commit message>'

========================================
Remote repository interactions
==================================
#check for remote changes, will not update anything that interferes with your work:
	git fetch

#pull remote changes:
	git pull

#push local branch commits:
	git push

assorted utility

#see recent commit log in detail (I don't use this one):
	git log

	git log --oneline

#save your work on your local branch without committing it
	git stash
